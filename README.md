My planner is an interactive online tool for individuals who struggle to balance everyday life with their schedules.
The website consists of daily to-do lists and calendars that help users visualize and organize their schedules. Along with an academic page that
allow users to maintain their grades through managing assignment/ exam due dates. Then the financial tracker will allow users to utilize their
money in a rational and educated manner. 
The purpose of My Planner is to transform users into productive and organized individuals who can maintain a work/student life balance.
HTML, CSS, Javascript is needed
Visual Studio Code is used to run the code.
The .html file is the structure that contains the code components, which is essentially the foundation. 
The .jpeg files are imported photos used in the code and need to be downloaded to be displayed on the website. 
The .csv is meant for the stored data that is utilized in the calendars
